# External learning sources: researched

Sources reviewed through public documentation, GitHub, search-indexed LinkedIn Learning course pages, and curriculum homepages on October 14, 2026. The user’s personal LinkedIn data was not accessed. Public pages are not a license to reproduce exercises.

### Official Python 3.14 documentation
https://docs.python.org/3.14/

**What Runtime should learn:** Primary semantics and standard-library reference; source of truth for current syntax.

### Harvard CS50P course weeks
https://cs50.harvard.edu/python/weeks/

**What Runtime should learn:** Well-sequenced programming concepts, error handling, testing, files, regex and OOP.

### Helsinki Python Programming MOOC 2025
https://programming-25.mooc.fi/

**What Runtime should learn:** Two-part curriculum, 1–7 introductory and 8–14 advanced; lots of applied problems.

### Google Python Class
https://developers.google.com/edu/python

**What Runtime should learn:** Text and runnable exercises; designed for learners with some programming experience.

### Google basic Python exercises
https://developers.google.com/edu/python/exercises/basic

**What Runtime should learn:** Short strings and lists functions followed by a larger word-count project.

### Exercism Python track
https://exercism.org/tracks/python

**What Runtime should learn:** Concept/practice separation, broad set of testable exercises.

### Exercism Python repository
https://github.com/exercism/python

**What Runtime should learn:** Open-source source structure: test files, concept/practice separation, license MIT; avoid direct copying.

### Exercism exercise authoring guidance
https://github.com/exercism/docs/blob/main/building/tracks/concept-exercises.md

**What Runtime should learn:** Just enough instruction, explicit prerequisites, hints, unit-test focus.

### Kaggle Python short course
https://www.kaggle.com/learn/python

**What Runtime should learn:** Data-oriented accelerated sequence; poor standalone base for absolute beginners.

### Kaggle Learn checker repository
https://github.com/Kaggle/learntools

**What Runtime should learn:** Useful reference for hint/check/solution architecture; Apache 2.0; depends on Kaggle infrastructure.

### LinkedIn Getting Started with Python
https://www.linkedin.com/learning/paths/getting-started-with-python

**What Runtime should learn:** Market-level benchmark: multi-course beginner progression and applications.

### LinkedIn Master Your Python Skills
https://www.linkedin.com/learning/paths/master-your-python-skills

**What Runtime should learn:** Advanced classes/functions, databases and coding challenges; path may change.

### TheAlgorithms Python
https://github.com/TheAlgorithms/Python

**What Runtime should learn:** Optional interview/algorithm inspiration, not recommended as beginner core; MIT.

### Python Data Science Handbook GitHub
https://github.com/jakevdp/PythonDataScienceHandbook

**What Runtime should learn:** Reference notebooks for NumPy/pandas/ML; text CC BY-NC-ND, code MIT and old Python versions.

### NumPy for absolute beginners
https://numpy.org/doc/stable/user/absolute_beginners.html

**What Runtime should learn:** Shapes, axes, dtypes, vectorization and copy/view semantics.

### pandas 10 minutes, current
https://pandas.pydata.org/docs/user_guide/10min.html

**What Runtime should learn:** Current Series/DataFrame, missing values, joins, groupby, EDA.

### pandas 2.0 migration notes
https://pandas.pydata.org/pandas-docs/version/2.0/whatsnew/v2.0.0.html

**What Runtime should learn:** Removed DataFrame.append and other past APIs; contrast old PDFs.

### scikit-learn getting started
https://scikit-learn.org/stable/getting_started.html

**What Runtime should learn:** Later ML subject, reliable pipeline and leakage guidance.

### Pyodide 314.0.7 package list
https://pyodide.org/en/stable/usage/packages-in-pyodide.html

**What Runtime should learn:** Check exact packages for pinned runtime; runtime currently only ships core.

### Python packaging guide
https://packaging.python.org/en/latest/tutorials/installing-packages/

**What Runtime should learn:** Correct local dependency/venv lessons, separate from browser execution.

### pytest get started
https://docs.pytest.org/en/stable/getting-started.html

**What Runtime should learn:** Reference for testing concepts even if Runtime uses custom grader.

### PEP 8 style
https://peps.python.org/pep-0008/

**What Runtime should learn:** Python conventions, emphasize readability over shortest possible code.
