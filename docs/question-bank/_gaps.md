## Phase 1 coverage review

The current Learn/Practice coverage review is [the canonical coverage matrix](../sql-phase1/COVERAGE.md). Twelve domains are available across both surfaces. All 88 lessons and 290 challenge records are individually reviewed in [the Phase 1 audit](../sql-phase1/LESSONS.md) and [Practice review](../sql-phase1/PRACTICE.md).

The latest additions target timed sensor gaps/islands and reciprocal home/away relationships. Existing questions already cover pivot/unpivot, fill-forward, interval merging, relational division, hierarchy variants, medians and histograms. No question count target or modality quota drove additions.

Write SQL remains dominant. Predict and Debug deliberately concentrate on NULL, joins, count semantics, rank/frame behavior, date boundaries, grain, deduplication and denominator errors. Native procedures and physical partitioning remain conceptual references because SQLite does not implement those features.
