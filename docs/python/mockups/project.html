Totals and discounts

Checkout needs the same numbers Runtime Market's order system records: subtotal, shipping, tax and total.

interactiveR01@starter.1uses: functions, dicts, rounding
The brief

Your cart from milestone 2 holds product IDs and quantities. Add cart_totals(cart, catalogue, promo) in pricing.py. It applies the promo discount to each line, gives free shipping at $50 (or with FREESHIP), adds 7% tax, and rounds every money value to cents.

DISCOUNTS = {"WELCOME10": 0.10, "SPRING15": 0.15, "BFCM25": 0.25} def cart_totals(cart, catalogue, promo=None): rate = DISCOUNTS.get(promo, 0) subtotal = 0 for product_id, qty in cart.items(): price = catalogue[product_id]["list_price"] subtotal += round(qty * price * (1 - rate), 2) shipping = 0 if subtotal > 50 else 5.99 tax = round(subtotal * 0.07, 2) return {"subtotal": round(subtotal, 2), "shipping_fee": shipping, "tax": tax, "total": round(subtotal + shipping + tax, 2)}
