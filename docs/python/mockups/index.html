Decisions to approve
  1. Same family as SQL. Header with mono path, amber active tab and status bar, split reading/workbench layout, amber mono section labels, Geist Sans and Mono. No new visual language.
  2. One workbench everywhere. File tabs (data files marked read-only), editor, Run / Check / Stop / Reset, then a results panel with Console and Checks tabs.
  3. Hidden tests. Shown as a pass count and their kinds ("empty catalogue, unknown product…"), never their inputs or expected values.
  4. Mode chips. Every lesson, question and milestone shows interactive, simulated or read-and-diagnose.
  5. Python signal colour. Green #3a6b35 / #9fd39a on mode chips only, the way SQL uses blue. Alternative: no subject colour, amber only.
  6. Code ligatures off. Geist Mono would turn >= into one symbol; learners need to see what they type.
  7. Projects. A milestone rail under the header, then brief, "done when" list and file tree on the left, multi-file editor and a deliverable preview on the right.
  8. Tools. The Explorer opens editions in the Playground or Database Lab; the Playground shows mounted data as read-only files.
