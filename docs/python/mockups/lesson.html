if: decide what happens to each order

Run code only when something is true, and choose between two outcomes.

interactiveneeds: comparison, logical operatorsR01@preview.1
You'll be able to
  • Write an if / else that picks one of two outcomes
  • Read which branch runs for a given record, before running it
  • Avoid the indentation and = / == slips that break conditions
The idea

A program runs top to bottom. if lets one block run only when its condition is True. Add else and exactly one of the two blocks runs, never both.

example 1 · free shipping▷ Run
subtotal = 66.49          # order O101217

if subtotal >= 50:
    shipping = 0
else:
    shipping = 5.99

print("shipping:", shipping)
shipping: 0
Runtime Market ships free at $50. Change subtotal to 6.49 and run it again: the other branch runs.
